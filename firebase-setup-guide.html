🔧 Firebase Setup Guide

Follow these steps to connect your testimonials system and admin panel to Firebase. Takes about 15 minutes. Free forever for your scale.

Step 1 — Create a Firebase Project

1
Go to Firebase Console

Visit console.firebase.google.com and sign in with your Google account.

2
Create New Project

Click "Add project" → name it (e.g. sandeep-portfolio) → disable Google Analytics if you don't need it → click Create project.

3
Register a Web App

In your project dashboard → click the </> (Web) icon → name it (e.g. portfolio-web) → click Register app.

Firebase shows you a firebaseConfig object. Copy it — you'll need it in Step 4.

// It looks like this:
const firebaseConfig = {
  apiKey:            "AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXX",
  authDomain:        "sandeep-portfolio.firebaseapp.com",
  projectId:         "sandeep-portfolio",
  storageBucket:     "sandeep-portfolio.appspot.com",
  messagingSenderId: "123456789012",
  appId:             "1:123456789012:web:abcdef123456"
};

Step 2 — Enable Authentication

4
Enable Email/Password Sign-In

In Firebase Console → Authentication (left sidebar) → Sign-in method tab → click Email/Password → Enable → Save.

5
Enable Google Sign-In

Still on Sign-in method → click Google → Enable → add your email as support email → Save.

6
Add Your Admin Account

Go to Authentication → Users tab → click "Add user" → enter your email and a strong password. This creates your admin account.

💡 The email you add here must match the ADMIN_EMAIL constant in admin-testimonials.html. Only this email gets admin access.

Step 3 — Create Firestore Database

7
Create Database

In Firebase Console → Firestore Database → Create database → choose Production mode → select a region (asia-south1 for India) → Done.

8
Set Firestore Security Rules

Go to Firestore → Rules tab → replace the default rules with these:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // testimonials collection
    match /testimonials/{docId} {

      // Anyone can READ approved testimonials
      allow read: if resource.data.approved == true;

      // Anyone can SUBMIT (write approved:false only)
      allow create: if
        request.resource.data.approved == false
        && request.resource.data.message.size() >= 20
        && request.resource.data.message.size() <= 600
        && request.resource.data.name.size() > 0;

      // Only authenticated admin can approve / delete
      allow update, delete: if
        request.auth != null
        && request.auth.token.email == "YOUR_ADMIN_EMAIL_HERE";

      // Admin can read ALL (including pending)
      allow read: if
        request.auth != null
        && request.auth.token.email == "YOUR_ADMIN_EMAIL_HERE";
    }
  }
}
⚠️ Replace "YOUR_ADMIN_EMAIL_HERE" with your actual email in the rules above before publishing.

Click Publish.

Step 4 — Paste Config into Your Files

9
Update testimonials.html

Open testimonials.html → find the FIREBASE_CONFIG object near the top of the <script type="module"> block → paste your config values from Step 3.

// BEFORE (placeholder):
const FIREBASE_CONFIG = {
  apiKey: "PASTE_YOUR_apiKey_HERE",
  ...
};

// AFTER (your real values):
const FIREBASE_CONFIG = {
  apiKey:            "AIzaSyXXXXXXXX",
  authDomain:        "sandeep-portfolio.firebaseapp.com",
  projectId:         "sandeep-portfolio",
  storageBucket:     "sandeep-portfolio.appspot.com",
  messagingSenderId: "123456789012",
  appId:             "1:123456789012:web:abcdef"
};
10
Update admin-testimonials.html

Open admin-testimonials.html → paste the same FIREBASE_CONFIG → also set your admin email:

const ADMIN_EMAIL = "your.email@gmail.com"; // ← your real email

Step 5 — Add Authorised Domain

11
Whitelist Your Domain

In Firebase Console → Authentication → Settings tab → Authorised domains → click Add domain → add your domain (e.g. sandeepsinghr.com or yourdomain.github.io).

💡 For local testing, localhost is already whitelisted by default.

How to See Who Has Signed Up / Logged In

👁
Firebase Console → Authentication → Users

Every person who creates an account or signs in with Google appears here with:

  • Display Name — from Google or what they entered
  • Email — their email address
  • Providers — Google / Email-Password
  • Created — account creation date and time
  • Last Sign-In — most recent login
  • UID — unique user ID for querying their data

You can disable, delete, or reset password for any user from this panel.

📊
Firestore → testimonials collection

Go to Firestore Database → browse the testimonials collection to see every submission with all fields. You can manually edit, approve, or delete documents here too.

💡 For your LMS, user progress is saved in localStorage (per browser) since you haven't connected it to Firebase yet. Once you're ready to sync LMS progress to Firebase too, add a users collection and save progress on each quiz completion.

✅ Checklist

Before going live:

  • ☐ Firebase project created
  • ☐ Email/Password + Google auth enabled
  • ☐ Admin user created in Authentication → Users
  • ☐ Firestore database created with security rules published
  • ☐ FIREBASE_CONFIG pasted into testimonials.html and admin-testimonials.html
  • ☐ ADMIN_EMAIL set in admin-testimonials.html
  • ☐ Your domain added to Authorised Domains
  • ☐ Tested on localhost — submitted a test testimonial, approved it in admin
  • ☐ Removed or hidden the config notice banner in testimonials.html
